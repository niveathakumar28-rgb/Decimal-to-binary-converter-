# Decimal to Binary Converter

## COA Mini Project

### Abstract

This project is a C-based Decimal to Binary Converter developed as a
Computer Organization and Architecture mini project.

The program converts a decimal integer into its equivalent binary
representation using the repeated division-by-2 method.

## Objectives

- Understand decimal and binary number systems.
- Implement decimal-to-binary conversion using C.
- Understand the repeated division-by-2 method.
- Demonstrate binary data representation.

## Algorithm

1. Read the decimal number.
2. Divide the number by 2.
3. Store the remainder.
4. Replace the number with the quotient.
5. Repeat until the quotient becomes zero.
6. Print the stored remainders in reverse order.

## Example

Input:
25

Output:
11001

Therefore:

25₁₀ = 11001₂
